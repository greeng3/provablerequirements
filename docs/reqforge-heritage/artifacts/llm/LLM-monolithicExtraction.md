ReqForge shall eventually support LLM-assisted extraction of
per-requirement artifacts from a monolithic input document (for
example, a legacy Word specification, a PDF standard, or a
lengthy Markdown design note). The extractor shall present
candidate requirements one by one or in batches for the user
to accept, modify, or discard. Initial output quality is not
expected to rival human authorship; the feature is judged on
how much manual transcription effort it saves relative to the
blank-page baseline. The feature is deferred.
