ReqForge shall eventually support publishing a System as a static,
browsable HTML site that mirrors the System / Project / Collection
structure, with typed-link navigation between artifacts. The site
is intended for consumption by non-ReqForge users (auditors,
external reviewers). The initial implementation is deferred.
