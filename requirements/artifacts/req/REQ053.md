A run announces what it is about to do only once it has decided to do it. Printing an intention
before establishing that there is work — naming a model, an endpoint, an engine — produces output
that describes an action rather than reporting one, and a reader has no way to tell the two apart
after the fact. Where the announced work then turns out to be unnecessary, the run has told the
operator something that never happened.

The case that matters is a run with nothing to do. Classification is additive, so a backlog that
is already classified leaves nothing to ask a model about, and skipping the request is correct.
Announcing it anyway makes a no-op indistinguishable from a completed run whose result happened to
match what was already recorded, and attributes to a model an opinion it was never asked for.

The tool therefore decides the scope of a run before describing it, states plainly when there is
nothing to do, and says how much work it is doing when there is. A run that skips work because it
is unnecessary also names the way to ask for that work deliberately, so that a state which is
correct to skip does not become a state the operator cannot get out of.
