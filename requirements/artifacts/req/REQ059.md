A claim about program state speaks of values, and a value it speaks of has to come from somewhere
before anything can be checked. Where the tool admits only one such value per claim, a property
relating several of them cannot be checked at all, however plainly it is written and however
ordinary the code it describes — and relating a function's inputs to its result is as ordinary as
program properties get. The limit is not in what the language can express but in what the tool
will supply, which makes it a limit on which true things can be proved.

An invariant is a claim about every state, so every value it speaks of is spoken of universally
whether or not the author marked it as such. The tool therefore quantifies over each variable an
invariant applies a predicate to. What is quantified over comes from the vocabulary: a predicate's
declaration is where its parameters are named, so it is where their sorts belong, said once for
every claim that applies the predicate rather than restated in each of them. An author who writes
a quantifier explicitly has said what they mean, and what they wrote stands.

This reading belongs to invariants in the code fragment and nowhere else. Elsewhere a free
variable may be the particular one there happens to be rather than every one there could be, and
other categories are checked by paths that perform no such quantification; claiming the reading
where it does not apply would state a requirement the author did not write, or describe work the
tool does not do.

Because the quantification is the tool's own reading rather than the author's words, the read-back
states it. The confirmation surface must show what will actually be checked, and a claim silently
ranging over more than the author wrote is precisely the divergence that surface exists to catch.

Nothing is supplied that the requirement did not determine. A variable whose sort the requirement
never gives, or gives inconsistently, has no domain, and a claim mentioning it is refused with
that variable named — never quantified over a domain the tool chose for it. A term that is a value
rather than a variable is not quantified over at all.

A sort named on a parameter is a sort like any other: it must be bound to something real before a
claim ranging over it can be checked, and the check that a bound predicate's parameter agrees with
the sort its argument ranges over applies at every position, not only where the author wrote a
quantifier.
