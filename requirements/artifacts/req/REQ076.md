provreq runs a human-tagged test and records the result as evidence marked asserted: it confirms the test ran and passed, never that passing it means the requirement holds — only a harness provreq itself generated from the formal claim carries that mechanical correspondence. A tagged test that runs and passes yields not-falsified evidence carrying the source location it came from; one that runs and fails yields a refutation; one that does not run, does not compile, or errors yields inconclusive, and a pass is never inferred from an exit code alone. This lets an un-formalized requirement earn evidence from a test a human vouches for, while the asserted marker keeps that evidence from ever reading as strong as a mechanically generated proof.
