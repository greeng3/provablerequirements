provreq ships a Model Context Protocol (MCP) server as a surface for AI coding agents to query the served subject's artifacts, traceability graph, and reports. The server is a thin stdio JSON-RPC adapter over provreq's REST API: it does not replace that API but translates provreq's operations into MCP's tools, resources, and prompts. Deployment is localhost-only, consistent with the single-operator server — the agent runs on the same host as provreq, so no authentication is required, and the server refuses a non-loopback target unless the operator explicitly overrides it. The management surface is read-only: artifact reads, full-text search, link and graph walks, and report generation are exposed as MCP tools; each artifact is a readable resource under provreq://artifact/<uuid>; and a baseline set of canned prompts covers common agent workflows.
