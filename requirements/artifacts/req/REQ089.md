An Anthropic provider entry may be configured to generate through the local Claude Code CLI instead of the HTTP Messages API. The transport is an explicit choice on the provider entry, not an inference from whether an API key happens to be present: an entry carries `transport: http` (the default, the existing `x-api-key` call against the Messages API) or `transport: cli` (a headless `claude` subprocess). The CLI transport is only meaningful for the Anthropic family; configuring it on any other family is a configuration error that names the offending entry, the way an unknown provider family already does.

The two transports differ in who pays. The HTTP transport bills the operator's Anthropic API credit balance; the CLI transport runs `claude` under the operator's own logged-in session, so generation draws on that subscription rather than API credits. This is the whole point of the choice — an operator with a subscription but no API credit balance can still drive the tool's LLM-backed actions.

The CLI transport is a peer adapter behind the same provider surface every other family implements, so the fallback chain, the health tracker, the operator-triggered retest, and the privacy gate treat it exactly as they treat an HTTP provider. It reports itself unavailable — the same signal the chain already uses to skip a keyless slot before issuing a doomed request — when the `claude` binary is absent or its stored session is not authenticated, and a failed generation is classified transient or permanent on the same terms as an HTTP failure so the health tracker's back-off and hard-disable behaviour is unchanged.

A subprocess transport carries obligations the HTTP transport does not. The operator's prompt is untrusted requirement text and is delivered to the subprocess on its standard input, never assembled into a shell command or a process argument. The subprocess is spawned with no tool access to the host and in a non-interactive mode, so a generation can neither read or write the server's files nor block waiting on an interactive permission prompt. A subprocess that does not return within the request's deadline is abandoned and reported as a timeout, the same transient failure an HTTP timeout produces.

The generic prompt surface carries a sampling temperature and an output-token ceiling that the headless CLI does not expose; the CLI transport omits what it cannot honour rather than pretending to apply it, and this loss of control is a known property of the transport, not a defect. With this requirement the operator chooses, per Anthropic provider entry, whether the tool's Anthropic generation is paid for through API credits or through their Claude subscription.
