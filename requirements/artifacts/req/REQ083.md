When a requirements source declares that an artifact is not expected to trace to code (ReqForge's expectsCodeTrace: false), that declaration is real information the seam carries whole onto the item. It rules out exactly one triage bucket, formalizable-now, without choosing between falsifiable-only and stays-prose, so on its own it seeds no bucket. The classifiers honour it rather than dropping it: the prose floor never over-claims formalizable-now for such an item, and the LLM classifier is told the declaration in its prompt and, whatever the model returns, a deterministic guard declines any formalizable-now answer for a ruled-out item. Declining leaves the item exactly as it was, never inventing or overwriting a judgement, so the operator is never shown or recorded a hint that contradicts the source's own declaration.
