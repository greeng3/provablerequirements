The triage classifier can bulk pre-sort the whole backlog with an LLM. The
provider is configured in the System config (`.provreq/system.json`) — written
through the UI or by `provreq set-llm` — which is the authoritative source every
LLM-backed step reads; a subject with no System config falls back to the
companion manifest's `llm:` block. A provider is an OpenAI-compatible endpoint
(covering Ollama and OpenAI), Anthropic, or Gemini, with a model and, where the
adapter needs one, a base URL. Any API key is stored in the System config file
itself at owner-only (0600) permissions; keyless endpoints (such as a local
Ollama) need no key. The classifier's output is advisory: the operator still
reviews and confirms or overrides it, any item the model omits or mislabels
falls back to stays-prose, and when no LLM is configured (or the endpoint is
unreachable) triage reports honestly and uses the prose-floor default.
