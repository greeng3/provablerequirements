Bulk triage (REQ085) may be asked to keep re-classifying the still-untriaged backlog round after round until it converges, rather than making a single pass. This exists because a classifier is allowed to decline an item (REQ052): a declined item is left untriaged rather than given a bucket it did not earn, and model nondeterminism declines a different subset each pass — so a single pass over a real backlog rarely drives the untriaged count to zero, and an operator otherwise has to re-run the pass by hand until it does.

A converging run re-asks only the items still untriaged. Each round classifies that residue and merges what landed onto the persisted state, exactly as one pass does (REQ054): a batch that fails costs one batch, and the next round — like the next run — resumes from what landed. The first round honours a re-classify request, since replacing existing classifications is a round-one act; every later round asks only about items that are still untriaged, so a bucket that already landed is never re-asked and the run can only shrink the untriaged set. The convergence never coerces the residue: an item the classifier keeps declining stays untriaged, the same honest empty state one pass leaves.

A converging run stops when nothing is left untriaged, when a round places nothing new — the classifier is stably declining the rest, so re-asking cannot help — or when a ceiling on the number of rounds is reached, so a classifier that would inch forward forever, or a provider that fails every round, cannot loop without end. When it stops with items still untriaged, it says so and how many, the same way a single stopped pass reports the residue it left; those items keep whatever they had, defaulted by nothing on their behalf.

The convergence is a property of the shared triage machinery, so the command line (`provreq triage --repeat`) and the web surface reach it through the same code and never diverge on how a backlog converges. A single pass is the one-round case of the same machinery, so the default one-pass behaviour is unchanged.
