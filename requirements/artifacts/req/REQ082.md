Beyond the read-only management tools, the MCP server exposes provreq's proof surface as tools: the requirement backlog with its coverage funnel, one requirement's formalization detail and last stored verdict, the installed verification engines and their status, running the engine ensemble on demand for a requirement, and setting a requirement's triage bucket. Verifying and triaging are the only write verbs the MCP exposes, and they are operator proof actions — running engines and recording a classification — not the authoring or editing of requirement content, which stays out of scope. This makes provreq's distinguishing feature, that its requirements can be proved, reachable by an agent through the same MCP seam it uses to read them.
