provreq scans a subject's own source for requirement-trace tags — Implements: and Verifies: — recognised only inside comments, uniformly across the languages it knows through a per-language comment grammar rather than a per-language parser, so the same scan serves any subject and not only Rust. Each tag names one or more requirement ids; a tag naming an id the subject does not declare is reported as an orphan and never silently dropped. Beyond the location, provreq resolves each tag to the source symbol it annotates — the declaration that follows the tag — so a later slice can run and rate that artifact by name. Resolution is a portable forward-scan over a small per-language declaration grammar; where no declaration is found the tag still carries its file and line, and provreq never treats an unresolved or orphan tag as evidence that the requirement holds.
