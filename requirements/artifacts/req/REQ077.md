provreq produces an on-demand traceability report: one row per requirement showing whether it is formalized, the code that implements it and the tests that verify it drawn from its Implements: and Verifies: tags, and the last stored verdict — proven, not-determined, or disproven — carrying the mechanical-or-asserted correspondence that keeps a human-tagged pass from ever reading as a mechanical proof. A requirement that has never been verified is shown as such, distinct from one an engine or a tagged test could not determine. Tags naming a requirement the subject does not declare are listed as orphans. The report reads stored state and scans source but runs no engine and no test, and is offered as human text and as JSON.
