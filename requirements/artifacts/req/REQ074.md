The tool authors a new requirement as a ReqForge artifact in the subject's collection from an id, a title, and prose: a valid artifact with a freshly minted uuid, active and not derived, its filename stem the id provreq reads. It refuses when the id already exists rather than clobbering it. The artifact arrives unreviewed — an empty review log — because authored prose is new text nobody has confirmed, so it passes through the review workflow like any other requirement, unlike a Doorstop import that carries a human baseline. This is provreq's own creation path for requirements, alongside import and any future UI or LLM authoring.
