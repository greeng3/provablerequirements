A verdict is durable state (REQ039) carrying the full provenance it was produced against. Re-verifying a requirement whose every provenance axis is unchanged re-runs the engine ensemble only to reach the identical verdict — tens of seconds for a real category-1 run, minutes for a cold prover build. That cost is what keeps verification out of a tight edit loop or a commit gate.

`verify` therefore serves the stored verdict without re-running the ensemble when nothing that could change the verdict has moved: the requirement prose, the admitted formalization (REQ045), the engines and the tool version (REQ049), the out-of-subject spec, trace, and UI axes (REQ028, REQ039), and the code the verdict covers. The code axis is a fingerprint of the verified scope (REQ071, verified_scope) — the member crate or model the verdict was checked against, or the whole subject when it was not narrowed — taken over the working tree, not the committed tree. An uncommitted edit to that code is therefore a cache miss, so a served verdict is never one the code as it stands could already contradict; this is the one way the code axis here is stricter than the commit-granular drift axis the display surface uses. The scope fingerprint over-approximates: it covers the whole scope unit rather than only the exact items the claim names, so a change the verdict does not truly depend on may still re-run it. That is the safe direction, and never the reverse — the cache never serves a verdict a fresh run could contradict.

A hit is only ever a hit when a fresh run would reach the same verdict; any determining axis that moved is a miss and re-runs. `--no-cache` forces a run against the unchanged world regardless. A served verdict is marked as served from cache, never presented as a freshly produced run.

This is the prerequisite for an enforcing gate: a gate that re-ran every requirement's ensemble on every invocation would be too slow to sit in a commit hook, which is exactly why a usable proof gate skips the work it can prove it does not need to repeat.
